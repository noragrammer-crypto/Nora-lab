## GitHub使えるようになったら、Vercelが一気に近くなった話

前回の記事では、

- Android（＋Termux）
- Obsidian
- GitHub

このあたりをつないで、「あ、これ普通に“開発フロー”じゃん」というところまで来た、という話を書いた。

で、その続き。

### GitHubが使える＝Vercelが使える、だった

GitHubにコードが置けるようになると、  
Vercelは **ほぼ設定画面ポチポチするだけ** になる。

正直なところ、

- サーバー？
- ビルド？
- 環境構築？

みたいな話は、今回はほぼ意識しなくていい。

GitHub連携 → リポジトリ選択 → Deploy  
以上。

「え、これだけ？」ってなるやつ。

### 試しにClaude Codeで“それっぽいアプリ”を作る

せっかくなので、実験用に

- ほんとに簡単なWebアプリ
- 機能は最小
- 見た目も最低限

みたいなやつを **Claude Code** に投げて作ってもらった。

やったことはほぼこれだけ👇

- 「Next.jsで簡単なページ作って」
- 「入力して結果出るだけのやつで」
- 「Vercelにそのまま載せたい」

すると、  
**ローカルで一応動く形のプロジェクト** が普通に出てくる。

もうこの時点で時代おかしい。

### GitHubにpush → Vercelにデプロイ

流れは本当にこれだけ。

1. Claude Codeが吐いたプロジェクトをGitHubにpush
2. Vercelで「New Project」
3. GitHubリポジトリ選択
4. Deploy

数分後、

- URLが発行される
- 普通にブラウザで動く
- スマホからも見れる

「え、もう公開されてるんだけど？」状態。

### Android＋AI＋Vercel、思った以上に“完成形”

今回やってみて思ったのは、

- PC前提じゃなくても
- フルIDEじゃなくても
- ガチガチの知識なくても

**「動くものを公開する」ところまでは行ける**

という事実。

しかも、

- コードはAIが8割書く
- 人間は方向と雑な要望出すだけ
- デプロイはVercelが面倒見る

完全に役割分担できてる。

### これ、個人開発のハードル完全に下がってない？

一昔前だと、

- サーバー借りて
- SSHで入って
- nginxがどうとか
- Nodeのバージョンがどうとか

やってたのが、

> GitHubに置いたらURL出ました

で終わる。

そりゃ  
「とりあえず作って出す」人が増えるわけだわ、という感想。

### まとめ：雑に作って、雑に公開できる時代

今回の結論。

- GitHub使えるようになったら世界が一段広がる
- Vercelは“公開ボタン”みたいな存在
- Claude Codeは「試作機」作るのに強すぎる

完成度を追い始めると別だけど、

> 思いついたものを  
> 動く形で  
> 外に出す

ここまでなら、  
もう **ほぼコストゼロ・時間ほぼゼロ** でできる。

次はこの流れを使って、

- Obsidian管理のメモをそのままWeb化するとか
- 個人用ツールを量産するとか

そのへん遊んでみようと思う。
