# find-stale-issue-archives.sh

## Overview

Among `<EpicDir>/docs/issues/issue-*.MD` (Issue Markdown snapshots generated by `xp_issue2md`),
Enumerate issue numbers of candidate files whose front matter is still `state: open`. For inquiries to GitHub API,
A definitive file system traversal-only script that does nothing.

Called from the `xp_issueArchiveFinalize` skill (`SoloXP/skills/xp_issueArchiveFinalize/SKILL.md`).

## Usage example

```bash
SoloXP/scripts/find-stale-issue-archives.sh <EpicDir>
```

`<EpicDir>` is the directory path of `<EpicName>` (e.g. `SoloXP`). The presence or absence of a trailing slash does not affect the result.

## Parameters

| Arguments | Required | Description |
|---|---|---|
| `$1` (EpicDir) | Required | Epic directory to scan. If omitted, displays Usage and ends with non-zero |

## Return value/output

- Standard output: Output candidate issue numbers (value of front matter `issue:`) one per line.
- Nothing is output if `<EpicDir>/docs/issues` does not exist or there are 0 candidates for `state: open`
  End normally (exit 0)
- Ignore files other than `issue-*.MD`

## Dependencies

- External commands: `grep`, `sed` (equivalent to POSIX standard. No additional installation required)
- No dependency on GitHub API/`gh` CLI
