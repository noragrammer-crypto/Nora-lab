```
Title: ops_meeting: Cross-sectional data loading → Department report → Director criticism → Action plan generation

## Essential Goal
Read GitHub/Obsidian data, make cross-disciplinary recommendations on "what we should focus on this week," and Nora approves and creates an issue.

## Background
The software workflow is almost complete.
The next bottleneck is increasing engagement.
There is a need for a system to regularly inject management perspectives.
This is not development task management, but automation of management meetings.

## Implementation flow (vertical conversation flow)
1. Load cross-sectional data from GitHub/Obsidian
2. Field report (by area)
   - Novel category: Kakuyomu PV/Likes/Bookmarks
   - Content category: four frames/note
   - PR/Marketing: X Engagement Followers
   - Development department: issue completion rate/number of PRs
3. Director criticism/suggestions (multiple perspectives)
4. Presentation of action plan
5. Approved by Nora → Issued

## Completion conditions
- Operates in a series from data loading to advice
- Granularity so that the output becomes the issue description as is
```
