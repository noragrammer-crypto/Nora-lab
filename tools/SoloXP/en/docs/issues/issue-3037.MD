## Overview
As required status check in GitHub Actions for PR from `feature/issue-*` branch to `main`
Add AllGREEN marker confirmation.

- Add new workflow `.github/workflows/allgreen-check.yml` with `pull_request` trigger
  - Guard the job with `if: startsWith(github.head_ref, 'feature/issue-')` and do not affect untargeted branches (`claude/...`, etc.)
- Create new `workflow/lib/check-allgreen.js` (pure logic) + `workflow/scripts/check-allgreen.js` (CLI)
  - Extract parent issue number from branch name and get comment history with `gh issue view <番号> --json comments`
  - Non-0 exit (fail-closed if both `[Auditor GREEN]` and `[Auditor doc OK]` are not present. Similarly, fail-closed when the `gh` call fails)
  - Call `gh` with the array argument of `execFileSync('gh', [...])`, and pass `github.head_ref` via `env:` (measure against shell injection, same pattern as existing `codecompass.yml`)
- Create a test in two layers: `workflow/__tests__/unit/*.unit.test.js` (`child_process` mock) + `workflow/__tests__/functional/*.functional.test.js` (real subprocess startup using fake `gh` binary)
