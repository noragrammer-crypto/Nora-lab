## Bug details
The AllGREEN explanation for `SoloXP/WORKFLOW.md` (around line 105) is written as a flow that immediately proceeds to `xp_RunE2ETests` → parent PR issue/close after AllGREEN.

> Original Codex indication (PR #20 review comment, `tools/SoloXP/Ja/WORKFLOW.md:105`):
> "When an operator follows this published workflow, AllGREEN leads directly to `xp_RunE2ETests` and then the parent PR/close action. This conflicts with `skills/xp_Director/SKILL.md:268-297`, which requires a separate Story-level Auditor run, Reviewer and documentation checks, the `spec_update` completion gate, and verification that every subtask PR was merged before creating the main PR. Following this summary can publish therefore a parent branch that is missing unmerged work or has not passed the required reviews."

The actual AllGREEN flow for `xp_Director/SKILL.md` includes the following required steps, but they are omitted from the WORKFLOW.md description:
- Story-level Auditor execution (`xp_Auditor test`)
- Code review by `xp_Reviewer`
- Document check (`xp_Auditor doc`)
- `spec_update` Task completion gate
- Confirm the merge of all subtask PRs

If this continues, readers who only read WORKFLOW.md may skip necessary gates and perform the wrong steps.

## Amendment policy (draft)
Add the above five gates to the AllGREEN section of `SoloXP/WORKFLOW.md`, or specify a link to the relevant section of `xp_Director/SKILL.md` and say "Click here for details."
