## Overview

Add runtime operation confirmation test for `$BODY_JSON` pattern of `kakuyomu_post_ab/SKILL.md` pointed out in Issue #1011.

`isValidJavaScript` of the existing test (`issue-822-kakuyomu-post-ab-eval-injection.unit.test.js`) is only syntax checked by `new Function(code)`. There is a lack of a test to verify that the code after expanding `textarea.value = $BODY_JSON` actually sets textarea.value correctly.

## Tests to add

### Add to unit test

Create a new `SoloXP/__tests__/issue-1011-body-json-runtime.unit.test.js`:

- Simulate textarea object using mock `document` + `querySelector`
- If a JSON.stringified string is directly assigned, the correct string will be set to `textarea.value`.
- Works correctly with the following special characters:
  - Line feed (`\n`)
  - backquotes (`` ` ``)
  - double quotes (`"`)
  - `${ }` Template literal string
- The eval code example in SKILL.md has a pattern of directly assigning `$BODY_JSON` without using `JSON.parse`.
