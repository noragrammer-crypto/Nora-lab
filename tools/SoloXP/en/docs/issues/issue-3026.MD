# #3026 [Task] xp_SecurityReviewer Create new skill

## Body

## Overview

Introducing the security review dedicated skill `xp_SecurityReviewer` to SoloXP.
Following the same structure as `SoloXP/skills/xp_Reviewer/SKILL.md` (code review skill), do the following:

- Call the built-in skill `security-review` (`/security-review`) to perform a security review of the current branch/PR difference
- Record review results as issue comments in `## xp_SecurityReviewer レポート` format
- For serious indications (equivalent to High Risk), an improvement recommendation issue is automatically raised using `gh issue create --title "[改善勧告] <概要>" --label bug` and the issue number is added to the report.
- Moderate/low risk indications are only comments (no user action required)

`security-review` A fallback (records the error content, skips it, and reports the fact to xp_Director) in case the skill call itself fails is also prepared following the fallback design of xp_Reviewer.

New file: `SoloXP/skills/xp_SecurityReviewer/SKILL.md`
