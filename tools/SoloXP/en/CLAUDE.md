# SoloXP English edition

`Ja/` is the source edition and `en/` is its English translation.

When a file in `Ja/` changes, update its corresponding file in `en/` and then update `.translation-manifest.json`. Keep paths and non-localized assets aligned unless an English-specific replacement is required.

Do not add dependencies on repositories outside `Nora-lab/tools/SoloXP/`. Links in the English edition must resolve within this directory or to stable public URLs.
