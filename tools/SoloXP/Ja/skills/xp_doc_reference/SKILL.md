# XP Doc Reference Skill

## コマンド

### `xp_doc_reference <epic_name> [package_name]`

実装ドキュメントを生成・更新する。
**コードが正。コードを読んで生成する。**

---

## 処理フロー

### 1. 対象ディレクトリを決定する

以下の優先順位でスキャン対象とドキュメント出力先を決定する：

| 優先度 | スキャン対象 | ドキュメント出力先 |
|--------|------------|------------------|
| 1（優先）| `api/<EpicName>/` が存在する場合 | `api/<EpicName>/docs/reference/` |
| 2 | `<EpicName>/scripts/` が存在する場合 | `<EpicName>/docs/reference/` |
| 3（フォールバック）| `<EpicName>/` 直下の `*.js` / `*.py` | `<EpicName>/docs/reference/` |

`package_name` が指定された場合はそのパッケージのみ対象とする。

### 2. 既存ドキュメントと比較

決定した出力先の既存ドキュメントと比較する。

### 3. 変更があったクラス・関数のドキュメントを更新

- 変更があったクラス・関数のMDを更新する
- 削除されたクラスのMDを削除する

---

## アウトプット

決定した出力先に `<packagename>/<ClassName>.md` を生成する。

各ドキュメントの内容：
- クラス・関数の概要
- パラメータ・戻り値
- 使用例
- 依存関係

---

## 注意事項

- コードを読んで生成するため、コードが最新であることを前提とする
- ドキュメントを元にコードを変更することはしない（一方通行）
