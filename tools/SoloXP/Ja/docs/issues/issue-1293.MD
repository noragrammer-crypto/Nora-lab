# #1293 [Bug] SoloXP/tests/e2e/ の Jest テストに Vercel デプロイ前提の xp_RunE2ETests が適用されスキップされる

## 本文

## 概要

`SoloXP/tests/e2e/` のテストは **SKILL.md ファイルの内容を Jest で検証するテスト** であり、Vercel へのデプロイを必要としない。
しかし `xp_RunE2ETests` スキルは「Vercel プレビュー URL への疎通確認 → `BASE_URL` 設定 → E2E 実行」という Playwright 前提のフローを踏む。
この不一致により、デプロイ不要なテストが疎通失敗でスキップされ続ける。

## depends_on

#1295

## SoloXP E2E テストの実態

```javascript
// tests/e2e/issue-826-story-level-auditor.test.js の例
const fs = require('fs');
const SKILLS_DIR = '/root/.claude/skills';

function readSkill(skillName) {
  const filePath = path.join(SKILLS_DIR, skillName, 'SKILL.md');
  return fs.readFileSync(filePath, 'utf-8');
}

describe('issue-826: Story完了時にStoryレベルのAuditorフェーズを導入する', () => {
  const directorSkill = readSkill('xp_Director');
  // → SKILL.md を読んで内容を検証するだけ。HTTP 通信なし
```

これらのテストはファイルシステムの読み取りだけで完結する。`BASE_URL` も Playwright も不要。

## 問題のある処理フロー

```
xp_Auditor (AllGREEN 後)
  → xp_RunE2ETests を呼ぶ
    → PREVIEW_URL 構築（壊れている、#1292 参照）
    → curl 疎通チェック → 失敗
    → "デプロイ未完了" としてスキップ
      ← SoloXP E2E テスト（Jestベース）が一切実行されない
```

## test と E2E の分割が問題を悪化させている点

SoloXP のテストは：
- `tests/unit/*.unit.test.js` → ユニットテスト（SKILL.md 内容の部分検証）
- `tests/functional/*.functional.test.js` → 機能テスト（複数スキルの連携を検証）
- `tests/e2e/*.test.js` → 「受け入れテスト」（SKILL.md の総合的な仕様適合チェック）

すべて **Jest + fs.readFileSync** で動作する。E2E ディレクトリにあっても「Playwright E2E」ではない。

## 修正案

`xp_RunE2ETests` スキルに「テストタイプの自動判定」を追加する:

1. `package.json` の `test:e2e` スクリプトを確認する
2. `playwright test` が含まれる → 従来どおり Vercel 疎通チェックを行う
3. `jest` が含まれる（SoloXP の場合） → Vercel 疎通チェックをスキップし、そのまま `npm run test:e2e` を実行する
