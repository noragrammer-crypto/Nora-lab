# #2936 [Task] pre-push.sh: symlink不可環境フォールバック + 無関係staged変更保護

## 本文

## 概要

`.claude/hooks/pre-push.sh` の2つの不具合を修正する（再現テスト＋修正実装を単一タスクで完結させる。CLAUDE.md TDD原則: バグ修正はワンタスク・ワンPR）。

1. symlink作成可否を `is_termux()` の判定だけで決めている。非Termuxでもsymlink作成が失敗しうる環境（例: symlink権限のないWindowsチェックアウト）でフォールバックがなく、`rm -rf` 後に `ln -s` が失敗するとスキルディレクトリが消失した状態でコミットされうる。
   - `can_create_symlinks()` を追加（`mktemp -d` + `ln -s` の実プローブ）。モード判定を `is_termux || ! can_create_symlinks` に変更。
   - 個々の `ln -s` 呼び出し自体にも失敗時 `cp -r` へのフォールバックを追加する。
2. `.claude/skills/` のドリフト修正コミット時、`git add -A` 後の無条件 `git commit` がpathspec無しで、pre-push実行時点で既にstageされていた無関係なWIP変更を巻き込んでコミットしてしまう。
   - 同期対象パスを `git add` する前に `git diff --cached --name-only` で既存staged内容を退避し、非空であれば自動コミットをスキップする（同期内容はgit add済みのまま残す）。

具体的な差分案はイシュー本文（#2738）に記載済み・ローカル検証済み。
