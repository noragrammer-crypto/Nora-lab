`feature/issue-*` ブランチから `main` へのPRに対し、GitHub Actions の required status check として
AllGREENマーカー確認を追加する。

- 新規ワークフロー `.github/workflows/allgreen-check.yml` を `pull_request` トリガーで追加する
  - ジョブは `if: startsWith(github.head_ref, 'feature/issue-')` でガードし、対象外ブランチ（`claude/...`等）には影響を与えない
- `workflow/lib/check-allgreen.js`（純粋ロジック）+ `workflow/scripts/check-allgreen.js`（CLI）を新規作成する
  - ブランチ名から親イシュー番号を抽出し、`gh issue view <番号> --json comments` でコメント履歴を取得
