# #3484 [Task] Issue Markdown finalizeスキル（xp_issueArchiveFinalize）新規作成

## 本文

## 概要

`<EpicName>/docs/issues/issue-*.MD` のうち front matter が `state: open` のファイルをGitHub上の最新状態と突合し、closed済みなら最新版Markdownへ差し替える新規スキル `xp_issueArchiveFinalize <EpicName>` を作成する。

### 処理内容

1. `grep -rl '^state: open$' <EpicName>/docs/issues/` で候補ファイルを洗い出す
2. 各候補ファイルの front matter `issue:` フィールドからissue番号を取得する
3. issue番号ごとに軽量な状態確認を行う: `gh issue view <n> --json state -q .state`（失敗時は `mcp__github__issue_read` method: `get` にフォールバック）
4. GitHub上で `closed` なら既存の `xp_issue2md <n>` をそのまま呼び出し、本文・コメント・front matter（`state: closed`含む）を丸ごと再生成する（新しいMarkdown生成ロジックは作らない。#2971の既存実装調査コメント参照）
5. GitHub上でまだ `open` なら何もしない
6. 完了後、走査件数・finalize件数・スキップ件数のサマリを報告する
