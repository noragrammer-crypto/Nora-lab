## バグ内容
`SoloXP/WORKFLOW.md` のAllGREEN説明（105行目付近）が、AllGREEN後すぐに `xp_RunE2ETests` → 親PR発行/クローズへ進む流れとして書かれている。

> Codex指摘原文（PR #20 review comment, `tools/SoloXP/Ja/WORKFLOW.md:105`）:
> "When an operator follows this published workflow, AllGREEN leads directly to `xp_RunE2ETests` and then the parent PR/close action. This conflicts with `skills/xp_Director/SKILL.md:268-297`, which requires a separate Story-level Auditor run, Reviewer and documentation checks, the `spec_update` completion gate, and verification that every subtask PR was merged before creating the main PR. Following this summary can therefore publish a parent branch that is missing unmerged work or has not passed the required reviews."

実際の `xp_Director/SKILL.md` のAllGREENフローには以下が必須ステップとして含まれるが、WORKFLOW.mdの説明では省略されている：
- Story-level Auditor実行（`xp_Auditor test`）
- `xp_Reviewer` によるコードレビュー
- ドキュメントチェック（`xp_Auditor doc`）
- `spec_update` タスク完了ゲート
- 全サブタスクPRのマージ確認

このままだと、WORKFLOW.mdだけを読んだ読者が必要なゲートを飛ばして誤った手順を実行しうる。

## 修正方針（案）
`SoloXP/WORKFLOW.md` のAllGREEN節に、上記5ゲートを追記するか、`xp_Director/SKILL.md` の該当セクションへのリンクを明記して「詳細はこちらを参照」とする。
