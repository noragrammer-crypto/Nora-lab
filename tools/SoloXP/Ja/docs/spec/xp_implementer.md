# xp_Implementer 機能仕様書

## 概要

xp_Implementer は Solo XP ワークフローの実装者スキル。
テストが示す仕様を忠実に実装し、結果を xp_Director に返す。
**コードを正しくすることが責務。テストの正しさは Auditor が判断する。**

---

## コマンド

| コマンド | 説明 |
|---|---|
| `xp_Implementer <issue_number>` | タスクイシューを読み込み実装する |

> xp_Director から呼ばれる。単独では実行しない。

---

## 処理フロー

### 1. [Implementer実行中] マーカーを記録する

イシューにコメントを記録してから作業を開始する:
```
[Implementer実行中]
```

### 2. 着手前チェック

- **ブランチ確認**: main ブランチのまま作業しない
- **依存イシューの確認**: `depends_on` があれば `[Auditor GREEN]` コメントを確認する。ない場合は着手しない

### 3. 実装

1. タスクイシューを読み込む（目的・見積もり・親ストーリー・既存テスト）
2. 既存テストを確認し、テストの期待動作を把握する
3. 既存コードのスタイル・設計に合わせて実装する
4. テストを実行して結果を記録する（GREEN でも RED でも次へ進む）
5. xp_Director に結果を報告して終了する

---

## 制約

- テストを修正・削除して GREEN にしてはならない
- テストに疑念があっても自己判断で止まらず、xp_Director 経由で Auditor に引き継ぐ
- 過度な抽象化・将来対応は行わない（現タスクの範囲に留める）
- E2E テストは対象外（ストーリー完了時に確認）
- セキュリティ問題（インジェクション・XSS 等）が発生しないよう注意する
