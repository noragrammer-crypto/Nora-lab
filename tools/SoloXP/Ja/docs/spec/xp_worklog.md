# xp_worklog 機能仕様書

## 概要

作業時間・トークン消費を GitHub イシューのコメントから集計し、レポート出力と `worklog/` への保存を行うプロンプト駆動スキル。

## コマンド

| コマンド | 説明 |
|---|---|
| `/xp_worklog <issue番号 or ストーリーカードパス>` | 指定ストーリーのサブイシューを含む作業ログを集計してレポート出力 |
| `/xp_worklog`（引数なし） | 直近クローズ Issue を全件集計してイテレーションレポートを出力 |

## 入力フォーマット

作業ログコメントとして以下を認識する：

```
作業開始 YYYY-MM-DD HH:MM JST
作業完了 YYYY-MM-DD HH:MM JST / 所要時間: XX分
tokens: prompt=XXXk completion=XXXk total=XXXk
model: <model-id>
作業中断 YYYY-MM-DD HH:MM JST
作業再開 YYYY-MM-DD HH:MM JST
```

### タイムスタンプ処理

- JST 明記あり → JST として解釈
- JST 明記なし（旧形式）→ UTC として解釈し JST に変換
- 中断・再開あり → 中断時間を除外して所要時間を計算
- `所要時間: XX分` 明記あり → その値を優先

### トークン消費フォーマット（#2141・#2143 で追加）

- `tokens: prompt=XXXk completion=XXXk total=XXXk` を `作業完了` 行の直後に付記（省略可）
- `model: <model-id>` を `tokens:` 行の次行に付記（省略可）
- `k` サフィックス = キロトークン単位（例: `350k` → 350,000 tokens）
- `k` なしの場合は整数として解釈
- フォーマット崩れ → ユーザーに確認（自動補完しない）

### トークン消費の集計ルール

- 複数セッションにまたがるイシューはトークンを**合算**する
- `tokens:` 行が存在しないセッション・イシューは「記録なし」として表示

```

ストーリー: #<番号> <タイトル>
期間: <最初のログ日付> 〜 <最後のログ日付>

### サマリー

| イシュー | タイトル | 時間 | トークン消費 |
|---|---|---|---|
| #<番号> | <タイトル> | <n>h <m>分 | prompt=Xk completion=Xk total=Xk |
```

## 保存フォーマット（`worklog/YYYY/MM/<epic>.md`）

```markdown
# <Epic名> — YYYY年MM月 作業記録

## サマリー
- 合計作業時間: Xh Ym
- 完了Issue数: N件（tokens記録あり: M件）
- 総トークン消費: Xk（Issue単位平均: Yk/issue）

## イシュー別記録

| Issue | タイトル | 開始時間 | 終了時間 | 作業時間 | トークン消費 | 備考 |
|-------|---------|---------|---------|---------|------------|------|
| #123  | タスク名 | YYYY-MM-DD HH:MM | YYYY-MM-DD HH:MM | XXm | prompt=Xk completion=Xk total=Xk | |
| #124  | タスク名 | YYYY-MM-DD HH:MM | YYYY-MM-DD HH:MM | XXm | 記録なし | (※推定) |
```

- 同月同エピックのファイルが既存の場合は既存行を保持しつつマージ更新
- 月をまたぐイシューは各月ファイルにそれぞれ記録

## Epic単位トークン消費集計（ROI）（#2144 で追加）

引数あり・引数なし双方のレポートに Epic 単位の ROI サマリーを追加する。

### 集計方法

1. `worklog/YYYY/MM/<epic名>.md` ファイルを走査し、対象 Epic の全月データを収集する
2. 複数月にまたがる Epic は各月ファイルのトークン消費を合算する（同一 Issue 番号が重複する場合は最新月エントリを優先）
3. `tokens:` 記録がない Issue は平均算出から除外し「記録なし」として表示する

### 算出値

| 項目 | 定義 |
|---|---|
| **完了Issue数** | worklogファイルに記録された Issue 行数の合計（tokens記録あり・なし両方を含む） |
| **総トークン消費** | `tokens:` 記録がある Issue の `total=Xk` 値の合算 |
| **Issue単位平均トークン消費** | 総トークン消費 ÷ `tokens:` 記録ありの Issue 数 |

### 出力フォーマット

```
### Epic単位トークン消費ROIサマリー

| Epic | 完了Issue数 | 総トークン消費 | Issue単位平均トークン消費 |
|------|------------|--------------|-------------------------|
| SoloXP | 12件 | 2,400k | 200k/issue |
| DiscordAIbot | 5件 | 800k | 160k/issue |
```

（完了Issue数は tokens 記録あり・なし両方を含む。平均は tokens 記録ありの Issue のみで計算）

## その他の処理

### エピック名判定
ラベル `epic/<EpicName>` から判定。日本語接尾辞は除去。ラベルなしは `misc`。

### タイムスタンプが未記録の場合
GitHub コメントの `createdAt`（UTC）を推定値として使用。`(※推定)` と明記。

### issue2md の再実行
`worklog/worklog_timestamp.md` の最終処理番号から再実行し `worklog_timestamp.md` を更新。
