# Solo XP ターゲット顧客分析

## 資源制約マトリクス

```
        │ 時間が豊富      │ 時間が制約
────────┼─────────────┼──────────────
金が    │ 富豪フリーランス│ 金持ち企業
豊富    │ (レアケース)    │ → API叩きまくる
        │                │   人間雇う
        │                │   Solo XP不要
────────┼─────────────┼──────────────
金が    │ Digital Farmer │ 貧乏サラリーマン
制約    │ ⭐Solo XP最適 │ → 詰んでる
        │ (Nora型)       │   (夜なべ労働)
        │                │   Solo XP効果薄
```

**Solo XPが輝くのは「金はないけど暇もない」層**

## プライマリターゲット: Digital Farmer

### 基本属性

```
年齢: 40-60代
職業: 引退エンジニア、セミリタイア、フリーランス
働き方: モバイルワーカー、カフェ巡回型
予算: 月5,000円以内
スキル: エンジニアリング経験あり（必須）
```

### 資源状況

**金（予算）**:
- ❌ エンタープライズAPI契約は無理
- ❌ 専任エンジニア雇用は無理
- ✅ 無料枠 + 少額課金なら可能

**時間（可用性）**:
- ❌ 連続した作業時間は取れない（移動が多い）
- ❌ 9-17時のような固定時間は取れない
- ✅ 断片的な時間は豊富（カフェ、移動中）
- ✅ 待ち時間を有効活用できる

**スキル（技術力）**:
- ✅ Git/GitHub操作に抵抗なし
- ✅ CLI操作に慣れている
- ✅ コードレビューができる
- ✅ 判断・承認ができる

### 典型的な1日

```
10:00 カフェA到着
10:00-10:15 Issue投げる（15分）
10:15-12:00 読書・小説執筆（奉行が裏で働く）

12:00 バイク移動（奉行は働き続ける）

13:00 カフェB到着
13:00-13:10 PR確認・承認（10分）
13:10-15:00 別作業（奉行が次のタスク）

15:00 バイク移動（奉行は働き続ける）

16:00 カフェC到着
16:00-16:05 最終確認（5分）
16:05-18:00 自分の小説執筆

人間作業: 30分
AI作業: 6時間（並行）
移動時間: 有効活用
```

### 価値提案

**「あなたの移動時間が、生産時間に変わります」**

- Issue投げたら、移動中にAIが働く
- カフェに着いたら、PRができてる
- 連続作業時間不要、判断だけでOK
- 予算は無料枠で収まる

### ペインポイント（解決する悩み）

1. **連続作業時間が取れない**
   - カフェ巡回、バイク移動
   - → Solo XPなら移動中もAI稼働

2. **予算が限定的**
   - エンタープライズツールは高すぎる
   - → 無料枠 + 少額課金で運用

3. **一人で全部やる必要がある**
   - チームがいない
   - → AIが複数メイドとして協力

4. **インフラ管理したくない**
   - サーバー運用面倒
   - → Codespaceが全部やってくれる

## セカンダリターゲット: 副業エンジニア

### 基本属性

```
年齢: 30-50代
職業: 正社員（本業） + 副業
働き方: 平日9-17本業、夜/週末に副業
予算: 月10,000円以内
スキル: 現役エンジニア
```

### 資源状況

**金（予算）**:
- ✅ 月1万円程度なら可能
- ❌ エンタープライズプランは厳しい

**時間（可用性）**:
- ❌ 平日昼間は完全ブロック（本業）
- ✅ 夜間・週末に断片的な時間
- ✅ 通勤時間に確認・承認可能

**スキル（技術力）**:
- ✅ 現役エンジニア（問題なし）

### 典型的な1日

```
07:00 通勤電車
07:00-07:10 Issue投げる

09:00-17:00 本業（AIが働く）

18:00 帰宅電車
18:00-18:10 PR確認・承認

19:00-22:00 家族時間（AIが次のタスク）

22:00 就寝前確認
22:00-22:05 最終チェック
```

### 価値提案

**「寝てる間に、AIがコードを書いてます」**

- 本業中もAIが副業を進める
- 通勤時間で指示・承認
- 週末に集中確認すればOK

### ペインポイント

1. **本業で時間が取れない**
   - 副業は夜・週末のみ
   - → 本業中にAIが働く

2. **体力・気力の限界**
   - 夜なべコーディングは辛い
   - → AIに任せて判断だけ

3. **納期プレッシャー**
   - クライアント案件の締切
   - → 24時間稼働で加速

## 非推奨ターゲット

### ❌ 金持ち企業・スタートアップ

**理由**:
- Claude API Enterpriseで無制限使える
- Codespace Teamで並列実行できる
- 専任エンジニア雇える
- Solo XPの制約内最適化は不要

**推奨ツール**:
- GitHub Copilot Enterprise
- Cursor Pro
- 人的リソース投入

### ❌ 非エンジニア（スキル不足）

**理由**:
- Git/GitHub操作が必須
- コードレビュー能力必要
- CLI操作に抵抗がある
- セットアップが難しい

**推奨ツール**:
- Replit Agent
- Bolt.new
- ノーコードツール

### ❌ 時間がない＋金もない学生

**理由**:
- 時間制約が厳しい（バイト＋授業）
- 待ち時間を活用できない
- 無料枠も限定的

**推奨**:
- 時間を作る
- または学生無料枠のあるツール

## マーケティングメッセージ

### キャッチコピー案

1. **「金持ちはAPI叩きまくる。俺はAIを待たせる。」**
2. **「カフェ移動中、AIが6時間働いてた話」**
3. **「無料枠で月収100万：Digital Farmerの生存戦略」**
4. **「貧乏だけど暇がある人のためのAI活用術」**
5. **「寝てる間に、PRが3つできてた」**

### 訴求ポイント

**効率性**:
- 「移動時間が生産時間に変わる」
- 「24時間稼働、あなたは判断だけ」

**経済性**:
- 「無料枠だけで運用可能」
- 「月5,000円以内で本格AI協調開発」

**柔軟性**:
- 「連続作業時間不要」
- 「スマホだけで指示・承認」

**自律性**:
- 「GitHub Issueが自動でPRに変わる」
- 「奉行が勝手に管理してくれる」

## 成功指標

### ユーザーがSolo XPに満足しているサイン

- Issue投げるだけで放置できてる
- 移動中にPRができてる実感
- 月のコストが予算内
- 「楽になった」と感じる
- 他の作業（小説執筆など）に集中できてる

### ユーザーがSolo XPに不満を持つサイン

- 毎回デバッグで介入が必要
- CPUタイム/トークンがすぐ尽きる
- PRの品質が低すぎる
- セットアップが面倒すぎた
- 結局手動の方が早い

---

**結論**: Solo XPは「金はないけど暇もない、でもスキルはある」層に最適化されたシステム。
