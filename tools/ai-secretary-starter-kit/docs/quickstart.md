# Quick start: the first loop

The goal is one small completed loop, not a perfect personal knowledge system.

## 1. Make a private copy

Copy `template/` into a new private GitHub repository. Rename nothing until you have completed the first loop.

## 2. Give the secretary a current brief

Edit only these two files:

- `command-center/profile.md`: stable preferences, constraints, and roles.
- `command-center/now.md`: this week's goal and the one problem you want to discuss.

Short, imperfect notes are enough.

## 3. Start a session

Give your agent this instruction:

> Read `AGENTS.md`, `command-center/`, and `wiki/index.md`. Summarize my current goal, identify one ambiguity, and propose one small next action. Do not perform external actions.

Correct its summary before continuing. This is the first quality gate.

## 4. Create one work record

When you agree on a task, create a GitHub Issue with:

- purpose;
- constraints;
- a small definition of done;
- the check that proves it is done.

The issue is the handoff between conversation and execution.

## 5. Close the loop

Review the pull request or completion note. If it contains a reusable lesson, add a short curated page to `wiki/` and link it from an index.

Repeat only when you need it. The system should reduce repeated explanations, not create administrative work.
