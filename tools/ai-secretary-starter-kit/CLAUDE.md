# Maintainer guidance

This directory is a public, copyable starter kit. Keep it lightweight and vendor-neutral.

## Design rules

- Files, not a hosted service, are the product.
- Markdown is the source of truth; YAML front matter carries only queryable metadata.
- `template/wiki/` is curated knowledge. `template/inbox/` is uncurated input.
- GitHub Issues record agreed work; pull requests record completed work.
- Keep the first-run path short enough to complete in about 15 minutes.
- Obsidian and agent skills are optional integrations, never a requirement for reading the kit.

## Public-repository rules

- Never add real personal profiles, credentials, tokens, private URLs, private conversation exports, or personally identifying examples.
- Do not add a dependency merely to demonstrate an idea.
- Preserve portability across Claude Code, Codex, Gemini, and ordinary text editors.
