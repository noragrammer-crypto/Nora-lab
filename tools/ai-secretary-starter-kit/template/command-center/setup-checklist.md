# Secretary capability setup

This is a capability checklist, not an instruction to connect every account.

## Ask the installed AI first

- [ ] List the tools and connectors actually available in this environment.
- [ ] Identify the current problem that would benefit from a connection.
- [ ] Recommend the minimum permissions and state the approval boundary.
- [ ] Record what is connected, what it can do, and how to revoke it.

## Core capabilities

- [ ] File and knowledge search — designated folders or vault only
- [ ] Web research — read-only public sources
- [ ] Work tracking — GitHub Issues, TODO list, or another chosen system

## Optional hands and feet

Enable only when useful now.

- [ ] Calendar — read; draft event changes; approval before create/change/cancel
- [ ] Email — search/read and draft; approval before send
- [ ] GitHub or project service — repository-scoped work tracking and completion reports
- [ ] Other work service — name, purpose, and boundary:
