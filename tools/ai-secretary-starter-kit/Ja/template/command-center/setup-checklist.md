# 秘書の能力セットアップ

これは能力の確認表であり、全アカウントをつなぐ指示ではありません。

## まず利用中AIへ確認する

- [ ] この環境で実際に使えるツールとコネクタを列挙する。
- [ ] 接続が役立つ現在の困りごとを確認する。
- [ ] 最小権限と承認境界を提案する。
- [ ] 接続済みのサービス、できること、解除方法を記録する。

## 基本能力

- [ ] ファイル・知識検索 — 指定したフォルダやVaultのみ
- [ ] Web調査 — 公開情報を読み取り専用で調べる
- [ ] 作業管理 — GitHub Issue、TODO、または選んだ管理先

## 任意の手足

- [ ] カレンダー — 読む・予定案まで。作成・変更・取消は承認後
- [ ] メール — 検索・閲覧・下書きまで。送信は承認後
- [ ] GitHub等のプロジェクト管理 — リポジトリ単位で作業と完了報告
