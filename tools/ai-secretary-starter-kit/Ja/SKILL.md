# AI秘書スターターキット

このキットのコピーを支援するときは、次の順で動きます。

1. `AGENTS.md`、`command-center/now.md`、`wiki/index.md` を読む。
2. 初回は `command-center/setup-checklist.md` を読み、この環境で実際に利用できる能力を明示する。
3. `inbox/` は一次資料として扱い、確認済みの長期知識と混同しない。
4. wikiには1ファイル1概念で追加し、YAMLの `type` と最寄りの `index.md` からのリンクを付ける。
5. 合意した実行作業はGitHub Issueにする。外部操作は明示承認なしに実行しない。
6. 秘密情報と個人文脈を公開出力へ含めない。
