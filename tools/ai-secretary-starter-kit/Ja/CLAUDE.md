# メンテナー向け指針

このディレクトリは公開・複製用のスターターキットです。軽量で、特定ベンダーに依存しない状態を保ちます。

## 設計原則

- ホスト型サービスではなく、ファイルがプロダクト。
- MarkdownをSSOTとし、YAML front matterには検索に必要な少量の項目だけを置く。
- `template/wiki/` は整理済み知識、`template/inbox/` は未整理の入力。
- GitHub Issueは合意した仕事、PRは完了報告。
- 最初の導線はおよそ15分で終わるようにする。
- ObsidianやAgent Skillは任意の連携であり、キットを読むための必須条件にしない。

## 公開リポジトリの規則

- 実在の個人プロフィール、認証情報、トークン、非公開URL、会話ログ、特定可能な例を追加しない。
- アイデア説明だけのために依存パッケージを追加しない。
- Claude Code、Codex、Gemini、通常のテキストエディタの間で持ち運べることを優先する。
